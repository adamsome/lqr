# lqr

Home bar manager: users track which bottles/ingredients they have in stock and browse cocktail recipes ("specs") they can make, including specs from users they follow.

## Stack

- Next.js 16 (App Router, Turbopack), React 19, TypeScript (strict)
- Clerk 7 for auth (`@clerk/nextjs`), MongoDB (`mongodb` driver, no ORM)
- Tailwind CSS 3 + shadcn/ui (Radix) components in `app/components/ui`
- Node 24 (`.nvmrc`; Vercel uses `engines` in `package.json`)
- Hosted on Vercel; every push to `main` deploys to production (`lqr.vercel.app`)

## Commands

- `npm run dev`: dev server on port 3000
- `npm run build`: production build (also type-checks)
- `npm run lint`: ESLint 9 flat config (`eslint.config.mjs`)
- `npm run format` / `npm run format:check`: Prettier
- `npm run typecheck`: `tsc --noEmit`
- `npm run test:e2e`: Playwright smoke tests (`e2e/`), read-only, against `BASE_URL` (default `http://localhost:3000`, so start the dev server first)
- CI (`.github/workflows/`): `ci.yml` runs typecheck, lint, format check and build on pushes and PRs; `smoke.yml` runs the smoke tests against each successful Vercel deployment.

If `node` reports "Bad CPU type", an old Intel Node is first on `PATH`; use the nvm Node 24 (`nvm use`). Delete `.next` if Turbopack cached a bad state.

## Layout

- `app/` holds everything (no `src/`). Import alias `@/*` maps to the repo root, e.g. `@/app/lib/utils`.
- `app/u/[username]/`: per-user pages: `specs`, `bar` (inventory by cabinet/shelf/category), `following`, `create-spec`
  - `specs/@modal/` is a parallel route for modals (e.g. change-user); `specs/default.tsx` is required for strict route matching.
- `app/api/`: route handlers (specs, stock, users/follow, staticdata)
- `app/lib/model/`: data access (Mongo + Clerk). Mostly server code (many files import `server-only`); `use-user.ts` is a client hook.
- `app/lib/types.ts`: shared types, including `PageProps`/`LayoutProps` (params/searchParams are Promises)
- `app/lib/generated-consts.ts`: generated by `scripts/`; do not edit by hand
- `json/`: static ingredient/category data served by `/api/staticdata`
- `scripts/`: separate npm package (ESM `.mjs`) for parsing CSV/Trello data and uploading specs to Mongo
- `proxy.ts`: Next 16 proxy (formerly middleware) running `clerkMiddleware()`; it only provides auth state and does no access control
- `todo.md`: the project's task tracker (Bugs, Chores, feature sections)

## Data

- Mongo collections: `user` (ingredient stock, denormalized counts like `specCount`/`followingCount`, FTUE state, excluded followees), `spec`, `follow`
- Users come from Clerk, plus hard-coded system users (`SYSTEM_USERS` in `app/lib/model/user.ts`: Classics, Modern Classics, etc.)
- Admins are listed in `app/lib/model/admin.ts`

## Conventions

- Prettier (`.prettierrc`): no semicolons, single quotes, Tailwind class sorting via `prettier-plugin-tailwindcss`; 2-space indent per `.editorconfig`. Run `npm run format`.
- Server code: `import { auth, currentUser, clerkClient } from '@clerk/nextjs/server'`; `await auth()` and `await clerkClient()`. Client hooks and components come from `@clerk/nextjs`.
- Access control lives in each page and route handler: pages that need sign-in call `await auth.protect()`; route handlers return 401 when signed out and 403/404 for other users' data. Never trust user IDs from the request body; filter writes by the signed-in user.
- Always `await props.params` / `props.searchParams` in pages, layouts, and route handlers.
- Use type-only imports (`import type`) when a type name collides with a local value.
- Don't call setState synchronously in effects (`react-hooks/set-state-in-effect` is an error). To reset state when a prop changes, compare with the previous value during render (see `app/api/use-mutate.ts`).

## Environment

`.env.local` (not committed) needs: `NEXT_PUBLIC_BASE_URL`, `MONGODB_URI`, `MONGODB_DB`, `NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY`, `CLERK_SECRET_KEY`, and the `NEXT_PUBLIC_CLERK_*` sign-in/up URLs. The app fetches its own `/api/staticdata` via `NEXT_PUBLIC_BASE_URL`, so run dev on that port.
